---
title: Socket.IO
description: Three namespaces — notifications, chat, and ticker — with automatic reconnect.
---

Socket.IO is **not** on the REST origin path. Local default is `http://localhost:4001`. Production uses your Socket.IO URL (playground: `NEXT_PUBLIC_SOCKETIO_URL`), not `https://api.mockforge.dev:4001`.

There is no `/stats` namespace (that stream is [WebSockets](/docs/websockets) only). Query `mfId` is ignored; HTTP `X-MF-ID` does not apply to this socket server.

## Namespaces

| Namespace        | Server events  | Interval           |
| ---------------- | -------------- | ------------------ |
| `/notifications` | `notification` | ~2s                |
| `/chat`          | `message`      | room pump + echoes |
| `/ticker`        | `tick`         | ~1s, one stock     |

Chat rooms use **`query.roomId`**. The server does not emit `user-joined` or `user-left`.

## Connect

```javascript
import { io } from "socket.io-client";

const origin = "http://localhost:4001"; // or your hosted Socket.IO URL

const notifications = io(`${origin}/notifications`, {
  path: "/socket.io",
  transports: ["websocket", "polling"],
});

notifications.on("notification", (data) => {
  console.log(data);
});

const chat = io(`${origin}/chat`, {
  path: "/socket.io",
  query: { roomId: "room-1" },
});

chat.on("message", (msg) => {
  console.log(msg);
});

chat.emit("message", {
  roomId: "room-1",
  body: "Hello",
});

const ticker = io(`${origin}/ticker`, { path: "/socket.io" });
ticker.on("tick", (stock) => {
  console.log(stock.symbol, stock.price);
});
```

Reconnect is built into the client (`reconnection: true` by default).

Lists return **arrays** (no REST envelope). Args: `limit` (default 10, max 100), `skip`, `search` where supported. Singular fields (`user(id)`, `product(id)`, …) accept `id` but the generator does not key off it.

The [Playground](/playground) GraphQL tab attaches `X-MF-ID` for the higher quota. See [Identity & rate limits](/docs/identity).

## Root fields

Lists: `users`, `products`, `posts`, `comments`, `todos`, `carts`, `messages`, `notifications`, `quotes`, `recipes`, `countries`, `companies`, `stocks`, `events`.

Singular: `user`, `product`, `post`, … (same names, singular).

```graphql
query GetUsers {
  users(limit: 5, skip: 0) {
    id
    firstName
    email
  }
}
```

## Mutations

`create*`, `update*`, `delete*` (e.g. `createUser`, `updateProduct`, `deleteTodo`). Create/update shallow-merge optional scalar args onto one generated row. Nested objects are not separate input types. Delete returns `{ deleted, id }`. Custom schemas are REST-only.

```graphql
mutation CreateUser {
  createUser(firstName: "Ada", email: "ada@example.com") {
    id
    firstName
    email
  }
}
```

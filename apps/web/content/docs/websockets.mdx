Connect with the browser `WebSocket` API or `ws` in Node. Host is the REST origin as `ws` / `wss`:

<DocsCurlList templates={["{ws}"]} />

| Path                | Interval      | Payload                                          |
| ------------------- | ------------- | ------------------------------------------------ |
| `/ws/stats`         | ~2s           | `{ "total": number }` plus `ping` / reply `pong` |
| `/ws/notifications` | ~2s           | one notification object                          |
| `/ws/chat/{roomId}` | room pump ~3s | message objects; clients can send JSON           |
| `/ws/ticker`        | ~1s           | one `Stock` object per tick                      |

There is no `{ type, timestamp, data }` wrapper. Try the [Playground](/playground) WebSocket tab (`/ws/chat/playground` is a ready room id).

## Connect

```javascript
const ws = new WebSocket("wss://api.mockforge.dev/ws/stats");

ws.onmessage = (event) => {
  if (event.data === "ping") {
    ws.send("pong");
    return;
  }
  console.log(JSON.parse(event.data));
};
```

```javascript
const chat = new WebSocket("wss://api.mockforge.dev/ws/chat/playground");
```

Stats expects `pong` on heartbeat. Socket.IO is a separate server — see [Socket.IO](/docs/socketio).

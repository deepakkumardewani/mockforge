## Protocols

- **[REST](/docs/rest)** — 14 entities, pagination, search, non-persistent writes
- **[GraphQL](/docs/graphql)** — same 14 entities, typed queries and mutations
- **[WebSockets](/docs/websockets)** — stats, notifications, chat, ticker
- **[Socket.IO](/docs/socketio)** — same live data with automatic reconnect
- **[Custom schemas](/docs/custom-schemas)** — your fields, public `GET /api/custom/{slug}`

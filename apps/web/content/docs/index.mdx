MockForge is a **hosted API**. Point your app at the origin and send requests. No signup required.

## Base URL

```
https://api.mockforge.dev
```

```bash
curl https://api.mockforge.dev/api/products?limit=5
```

Call REST, GraphQL, WebSockets, and Socket.io directly from your application. The [Playground](/playground) is optional if you want to explore the same API in the browser.

## What's available

- **REST API** — 14 entities, full CRUD, pagination, search
- **GraphQL** — same 14 entities via a typed GraphQL schema
- **WebSockets** — live streams for stats, notifications, chat, stock ticker
- **Socket.io** — same real-time data with automatic reconnection
- **Custom Schemas** — define your own schema, get a dedicated hosted endpoint

## Getting started

Send a request to the origin above, then browse the sidebar for protocol details and copy-paste examples.

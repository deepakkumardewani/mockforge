---
title: Messages
description: Generated messages. Writes do not persist.
---

`GET /api/messages`. Envelope and verbs: [REST API](/docs/rest).

## Fields

| Field        | Type         |
| ------------ | ------------ |
| `id`         | number       |
| `senderId`   | number       |
| `receiverId` | number       |
| `roomId`     | number       |
| `body`       | string       |
| `read`       | boolean      |
| `createdAt`  | string (ISO) |

## Sample

```json
{
  "data": {
    "id": 1,
    "senderId": 52,
    "receiverId": 94,
    "roomId": 9,
    "body": "Amplexus repudiandae bene aetas vulnus centum.",
    "read": false,
    "createdAt": "2026-05-23T03:43:19.922Z"
  }
}
```

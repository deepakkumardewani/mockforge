`GET /api/products`. Envelope and verbs: [REST API](/docs/rest).

## Fields

| Field                | Type            |
| -------------------- | --------------- |
| `id`                 | number          |
| `title`              | string          |
| `description`        | string          |
| `price`              | number          |
| `discountPercentage` | number          |
| `rating`             | number          |
| `stock`              | number          |
| `brand`              | string          |
| `category`           | string          |
| `thumbnail`          | string (URL)    |
| `images`             | string[] (URLs) |
| `sku`                | string          |
| `weight`             | number          |
| `createdAt`          | string (ISO)    |

---
title: Countries
description: Generated country rows. Writes do not persist.
---

`GET /api/countries`. Envelope and verbs: [REST API](/docs/rest).

## Fields

| Field        | Type         |
| ------------ | ------------ |
| `id`         | number       |
| `name`       | string       |
| `code`       | string       |
| `capital`    | string       |
| `region`     | string       |
| `subregion`  | string       |
| `population` | number       |
| `area`       | number       |
| `currency`   | string       |
| `language`   | string       |
| `flag`       | string       |
| `createdAt`  | string (ISO) |

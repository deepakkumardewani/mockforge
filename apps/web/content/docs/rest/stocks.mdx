---
title: Stocks
description: Generated quotes. Writes do not persist.
---

`GET /api/stocks`. Live ticks: [WebSockets](/docs/websockets) / [Socket.IO](/docs/socketio). Envelope: [REST API](/docs/rest).

## Fields

| Field           | Type         |
| --------------- | ------------ |
| `id`            | number       |
| `symbol`        | string       |
| `name`          | string       |
| `price`         | number       |
| `change`        | number       |
| `changePercent` | number       |
| `open`          | number       |
| `high`          | number       |
| `low`           | number       |
| `volume`        | number       |
| `marketCap`     | number       |
| `exchange`      | string       |
| `updatedAt`     | string (ISO) |

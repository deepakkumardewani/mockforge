---
title: Users
description: Generated user profiles. Writes do not persist.
---

`GET /api/users`. Envelope and verbs: [REST API](/docs/rest).

## Fields

| Field       | Type                                        |
| ----------- | ------------------------------------------- |
| `id`        | number                                      |
| `firstName` | string                                      |
| `lastName`  | string                                      |
| `email`     | string                                      |
| `username`  | string                                      |
| `phone`     | string                                      |
| `avatar`    | string (URL)                                |
| `birthDate` | string (ISO)                                |
| `address`   | `{ street, city, state, zipCode, country }` |
| `company`   | string                                      |
| `jobTitle`  | string                                      |
| `createdAt` | string (ISO)                                |

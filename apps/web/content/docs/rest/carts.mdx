`GET /api/carts`. Envelope and verbs: [REST API](/docs/rest).

## Fields

| Field             | Type                                                                                                                    |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `id`              | number                                                                                                                  |
| `userId`          | number                                                                                                                  |
| `products`        | `CartItem[]` — `productId`, `title`, `price`, `quantity`, `total`, `discountPercentage`, `discountedTotal`, `thumbnail` |
| `total`           | number                                                                                                                  |
| `discountedTotal` | number                                                                                                                  |
| `totalProducts`   | number                                                                                                                  |
| `totalQuantity`   | number                                                                                                                  |
| `createdAt`       | string (ISO)                                                                                                            |

---
title: Todos
description: Generated tasks. Writes do not persist.
---

`GET /api/todos`. Envelope and verbs: [REST API](/docs/rest).

## Fields

| Field       | Type                              |
| ----------- | --------------------------------- |
| `id`        | number                            |
| `userId`    | number                            |
| `todo`      | string                            |
| `completed` | boolean                           |
| `priority`  | `"low"` \| `"medium"` \| `"high"` |
| `dueDate`   | string (ISO)                      |
| `createdAt` | string (ISO)                      |

## Sample

```json
{
  "data": {
    "id": 1,
    "userId": 3,
    "todo": "Crur absque sperno summa quo congregatio ex crepusculum.",
    "completed": false,
    "priority": "medium",
    "dueDate": "2026-06-22T12:08:48.551Z",
    "createdAt": "2026-05-23T07:01:13.420Z"
  }
}
```

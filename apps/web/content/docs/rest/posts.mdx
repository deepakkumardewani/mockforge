---
title: Posts
description: Generated posts. Writes do not persist.
---

`GET /api/posts`. Envelope and verbs: [REST API](/docs/rest).

## Fields

| Field       | Type         |
| ----------- | ------------ |
| `id`        | number       |
| `title`     | string       |
| `body`      | string       |
| `userId`    | number       |
| `tags`      | string[]     |
| `reactions` | number       |
| `views`     | number       |
| `createdAt` | string (ISO) |

## Sample

```json
{
  "data": {
    "id": 1,
    "title": "Talio paulatim speciosus creta depopulo vox.",
    "body": "Multi-paragraph generated body.",
    "userId": 7,
    "tags": ["aut", "sollicito", "umbra"],
    "reactions": 126,
    "views": 3272,
    "createdAt": "2026-05-23T04:28:37.452Z"
  }
}
```

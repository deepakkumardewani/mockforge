`GET /api/comments`. Envelope and verbs: [REST API](/docs/rest).

## Fields

| Field       | Type         |
| ----------- | ------------ |
| `id`        | number       |
| `postId`    | number       |
| `userId`    | number       |
| `body`      | string       |
| `author`    | string       |
| `email`     | string       |
| `createdAt` | string (ISO) |

```json
{
  "data": {

    "postId": 95,
    "userId": 82,

    "author": "Marc Durgan",
    "email": "Brittany.Franey@yahoo.com",
    "createdAt": "2026-05-22T20:46:28.971Z"
  }
}
```

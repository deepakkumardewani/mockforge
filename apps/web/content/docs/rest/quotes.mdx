---
title: Quotes
description: Generated quotes. Writes do not persist.
---

`GET /api/quotes`. Envelope and verbs: [REST API](/docs/rest).

## Fields

| Field       | Type         |
| ----------- | ------------ |
| `id`        | number       |
| `content`   | string       |
| `author`    | string       |
| `category`  | string       |
| `likes`     | number       |
| `createdAt` | string (ISO) |

## Sample

```json
{
  "data": {
    "id": 1,
    "content": "Vulgo sumptus suscipit verbera confero.",
    "author": "Dr. Shannon Jenkins II",
    "category": "cibo",
    "likes": 356,
    "createdAt": "2026-05-22T21:07:14.034Z"
  }
}
```

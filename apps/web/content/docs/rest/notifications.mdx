---
title: Notifications
description: Generated notifications. Writes do not persist.
---

`GET /api/notifications`. Envelope and verbs: [REST API](/docs/rest).

## Fields

| Field       | Type                                                |
| ----------- | --------------------------------------------------- |
| `id`        | number                                              |
| `userId`    | number                                              |
| `type`      | `"info"` \| `"warning"` \| `"success"` \| `"error"` |
| `title`     | string                                              |
| `message`   | string                                              |
| `read`      | boolean                                             |
| `createdAt` | string (ISO)                                        |

## Sample

```json
{
  "data": {
    "id": 1,
    "userId": 7,
    "type": "error",
    "title": "Conduco tempus tergiversatio.",
    "message": "Adflicto apparatus video aggredior.",
    "read": false,
    "createdAt": "2026-05-23T02:52:33.261Z"
  }
}
```

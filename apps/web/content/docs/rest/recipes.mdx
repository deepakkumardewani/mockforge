---
title: Recipes
description: Generated recipes. Writes do not persist.
---

`GET /api/recipes`. Envelope and verbs: [REST API](/docs/rest).

## Fields

| Field             | Type                               |
| ----------------- | ---------------------------------- |
| `id`              | number                             |
| `name`            | string                             |
| `description`     | string                             |
| `prepTimeMinutes` | number                             |
| `cookTimeMinutes` | number                             |
| `servings`        | number                             |
| `difficulty`      | `"easy"` \| `"medium"` \| `"hard"` |
| `cuisine`         | string                             |
| `calories`        | number                             |
| `tags`            | string[]                           |
| `ingredients`     | `{ name, quantity, unit }[]`       |
| `instructions`    | string[]                           |
| `image`           | string (URL)                       |
| `rating`          | number                             |
| `createdAt`       | string (ISO)                       |
